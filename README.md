# CYTOPLASM — BOUNCE & BLAST v0.7.0

**PC 16:9 · 1280×720 · GDevelop 5 + browser HTML demo.**

У v0.7 пріоритет — драйв, а не складне конструювання. Нитки та меню здібностей прибрані з основних кімнат. Одна органічна цитоплазма сама реагує на контекст.

## Керування

| Клавіша | Дія |
|---|---|
| A / D або ← / → | Рух, із керуванням у повітрі |
| Space | Стрибок / відштовхнутися від желе |
| E | Миттєво випустити желе |
| R | Підірвати останнє активне желе; сусідні вибухають ланцюгом |
| Миша (лише напрямок) | Прицілювання, без натискань кнопок |
| W/S | Лазити збоку желе, якщо герой прилипає |
| N | Перезапуск кімнати |

Важливо: управління E/R прив'язане до **фізичного коду клавіші** (`KeyboardEvent.code`), тому працює навіть із українською розкладкою.

## Контекстні взаємодії

- **Bounce**: желе створює пружну поверхню. При зіткненні герой автоматично підстрибує, а успішні комбо дають невеликий бонус.
- **Capture**: влучання желе у рухомий ящик або стілець захоплює його й утворює обволікаючу пружну оболонку.
- **Blast**: R підриває останній шматок желе; поштовх розганяє героя, рухає предмети, сусідні желе детонують каскадом.
- **Pressure**: важкий вантаж стискає желе і після накопичення тиску викликає фізичний вибух.
- **Biomass**: ресурс поступово відновлюється. Вибух, старіння та падіння за межі світу супроводжуються ефектом і поверненням біомаси — жодне желе не зникає без реакції.

## Три короткі рівні

1. **BOUNCE PLAYGROUND**: безпечні тренування, стрибки, нові гелеві платформи.
2. **BLAST RUN**: прірви та каскадні вибухи, які підкидають героя й предмети.
3. **FLYING JUNK**: стілець, ящики, захоплення й вибухова фізика.

## Склад проєкту

- `Cytoplasm_GDevelop_v070.json` — нативний GDevelop 5-проєкт із JavaScript-подією в сцені.
- `GameScene_v070.js` — код події для GDevelop.
- `GameCore_v070.js` — спільна ігрова логіка для HTML та GDevelop.
- `index.html`, `docs/index.html` — автономне браузерне демо. **Це не офіційний GDevelop-експорт.**
- `tests/test_core_v070.cjs` — логічні тести фізичних взаємодій.

**Примітка:** фізика аркадна, а не повноцінна симуляція Box2D. GDevelop Preview потрібно перевірити вручну після імпорту JSON. Окремо перевіряйте баланс проходження на реальному PC.
