# CYTOPLASM v1.0 — LIVING WORLD

Один наскрізний біологічний рівень (орієнтовно 3 хв дослідження), розвиток перевіреної v0.9.

## Керування
- **A / D** — рух; **W** — стрибок.
- **Лівий клік** — постріл цитоплазмою до курсора (дальність 355).
- **R** — підірвати найближче до курсора желе.
- **N** — перезапуск.
- **E** — не використовується.

## Нове в Living World
- **П’ять верхніх мембранних маршрутів** над прірвами: вони потребують желейного відскоку, але дозволяють обійти частину небезпек і зібрати додаткові капсули. Нижній маршрут із v0.9 не вилучено.
- **Жива тканина:** мембрани дихають, війки рухаються, органели пульсують, кілька теплих потоків допомагають під час стрибків.
- **Бактерії мають різну тактику:** одиночні спори, попереджені залпи по три, бактерії-носії гарантовано залишають клітинний ресурс. Пряме желе ненадовго оглушує, але не заморожує ворога.
- **Реальні уламки:** вибух випускає фізичні осколки, які летять, відбиваються від тканини, уражають ворогів і можуть запустити сусідню бульбашку. Є індикатор ланцюгових реакцій.
- Збережено: ядро героя, зміну розміру від запасу цитоплазми, **5 базових пострілів**, біокапсули, **30-секундний Bio Surge**, віруси-супербатути, постріли бактерій, цитоплазмові щити, гарячу клітину, електричний клапан, чекпоїнти.

## Формат
- Самодостатній `index.html` без зовнішніх залежностей.
- `Cytoplasm_GDevelop_v100.json`, `GameCore_v100.js`, `GameScene_v100.js` для GDevelop.
- Ніякої складної системи ниток чи нової кнопки здібностей.

**Прототип:** таймінг 3 хв орієнтовний; швидкість проходження залежить від стрибків, дослідження та бою.
