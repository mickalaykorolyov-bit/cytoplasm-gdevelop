# CYTOPLASM — Living Architecture v0.5.0

**PC горизонтальний прототип 16:9 (1280×720), дві кімнати.**

## Керування без меню здібностей

- **A / D** або ← / → — рух; відпускання зупиняє героя.
- **Space** або W / ↑ — стрибок.
- **F** — взяти / покласти предмет; біля старішого зафіксованого предмета можна повернути цитоплазму.
- **E** — кинути предмет у повільний політ, навіть під час стрибка.
- **R** — зафіксувати останній кинутий предмет / звільнити повторним натисканням зі збереженим імпульсом.
- **T** — кімната 2: створити живу нитку від останнього зафіксованого предмета до найближчої опори.
- **N** — перезапустити кімнату (R більше не перезапускає гру).

## Липка цитоплазма

Фіксація предмета створює широку горизонтальну мембрану на ньому, незалежно від його кута обертання. Герой може приземлятися та стояти на мембрані, не зісковзуючи з країв. Щоб відірватися, стрибни. Предмети на живих нитках також мають липку оболонку, яка рухається з ними.

Звільнення предмета розчиняє мембрану, повертає біомасу та відновлює його швидкість і обертання. Липкість не має окремої вартості понад звичайну фіксацію.

## Обмеження

Спрощена фізика, не повноцінний rigid-body sandbox. Автономне HTML-прев'ю використовує Canvas2D, а не офіційний експорт GDevelop. GDevelop JSON має вбудовану JS-подію, але Preview у редакторі потребує окремої ручної перевірки.
