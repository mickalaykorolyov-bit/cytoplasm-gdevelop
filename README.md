# CYTOPLASM v0.8.1 — Traversal Challenge

## Головна зміна
Гравець більше не може стояти на старті та обстрілювати весь рівень. **Дальність пострілу — 340 ігрових пікселів**; згусток летить від героя до точки кліку й зупиняється на першій твердій перешкоді. Потрапляння в двері не активує вихід — потрібно фізично дістатися дверей.

## Основна кімната — клавіша 0 (також стартова)
Дві прірви, довші за можливість звичайного стрибка; побудуй желе-платформу над прірвою й відштовхнися до іншого берега. Орієнтири для желе намальовані пунктиром; ризик — падіння в небезпечне середовище з миттєвим відновленням. Другий етап підіймається ще вище. Звичайне желе залишається одним батутом, а не набір здібностей.

## Лабораторія
Клавіші **1–6** ведуть до старих контекстних лабораторій (меблі, равлик/павук, свічка/труба, електрика, сейф/шип, магніт). На них діють ті самі правила пострілу — 340 px і зіткнення зі стінами.

## Керування
A/D — біг; W — стрибок; лівий клік — постріл до курсора (в межах дальності); R — вибух желе біля курсора; 0 — стартовий маршрут; 1–6 — лабораторії; N — перезапуск. E — вимкнено.

## Технічні зауваги
`lite.html` — оптимізований для Chrome варіант (960×540 внутрішня роздільність, 30 кадрів/с, обмежені графічні ефекти). `index.html` — повна версія. Всі матеріали локальні без CDN. Логіка в `GameCore_v081.js`; `GameScene_v081.js` для GDevelop, JSON-проєкт додається.
