# CYTOPLASM v0.7.2 — Jelly Personality & Shooting Animation

**Іграбельний браузерний прототип · 1280×720 · GDevelop 5 JSON**

## Керування
- **A / D** — рух, стрілки ліворуч/праворуч також працюють.
- **W** — стрибок або відштовхування від липкої цитоплазми. Працює незалежно від розкладки.
- **Лівий клік** — герой випускає видимий згусток; він швидко летить від персонажа **до точки кліку** й там розгортається в желе.
- **R** — підірвати желе, найближче до курсора. Підведи курсор до конкретної кульки й натисни R; будь-яка бульбашка вибухає. Вибухи можуть запускати сусідні.
- **S** — причепитися до цитоплазми та повзти вгору. **W** — відштовхнутися від неї.
- **N** — перезапустити поточну кімнату.
- **E повністю вимкнено**. Пробіл не використовується для стрибка.

## Кожне желе має характер (за чергою, без перемикання здібностей)

| Желе | Колір | Відскок і вибух |
|---|---|---|
| Пружне | М'ятний ↥ | Сильніший відскок; підкидальний вибух |
| Фугас | Рожевий ✹ | Широка потужна ударна хвиля |
| Реактивне | Блакитний ↑ | Вибух спрямований угору, як реактивний струмінь |
| Каскадне | Фіолетовий ⚡ | Вибух передається іншим бульбашкам на більшій відстані |
| Меблі | Золотий ↑↑ | Оболонка супербатут; вибух запускає предмет як снаряд |
| Тиск | Помаранчевий ! | На важкому ящику накопичується тиск і відбувається вибух |

Кожен клік циклічно створює наступне «вільне» желе (↥ → ✹ → ↑ → ⚡). Наступний тип відображається на HUD. **Кожне можна підірвати**, незалежно від того, чи є всередині меблі.

Коли желе завершує життя, переповнює ліміт, або падає за межі кімнати, воно лускає з частинками та повертає біомасу; не зникає мовчки.

## Три кімнати
1. **Bounce Playground** — тест усіх желейних характерів, пострілів та стрибків.
2. **Blast Run** — вибухи, ударні хвилі і важкий ящик із накопиченням тиску.
3. **Furniture Rocket** — обволікай стілець та запусти його вибухом у перешкоду.

`index.html`, `docs/index.html` — standalone HTML-прев’ю без мережевих залежностей. `GameCore_v072.js` — ігрова логіка, `GameScene_v072.js` — подія для GDevelop, `Cytoplasm_GDevelop_v072.json` — проєкт для GDevelop. HTML не є нативним експортом GDevelop: запуск у GDevelop Preview потребує ручної перевірки.
