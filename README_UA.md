# CYTOPLASM: Living Architecture v0.6 (PC / 16:9)

Наступна версія після v0.5.1, із фізичною моделлю маленької живої істоти. **Один матеріал — багато взаємодій, без меню здібностей.**

## Керування

| Клавіша | Дія |
| --- | --- |
| **A / D** або ←/→ | Рух |
| **Space** | Стрибок; відштовхнутися від липкої оболонки |
| **F** | Підібрати / покласти предмет |
| **E (утримуй і відпусти)** | Зарядити силу та кинути предмет; зелена пунктирна траєкторія й індикатор сили |
| **W / S** або ↑/↓ | Лазити вгору/вниз по цитоплазмі; під час заряджання E змінювати кут |
| **R** | Зафіксувати останній кинутий предмет у польоті / звільнити його |
| **T** | Прикріпити живу нитку в кімнаті 2 |
| **N** | Перезапустити поточну кімнату |

Працює з українською розкладкою завдяки `KeyboardEvent.code`. Фізика кидків прототипна, але заряджання, траєкторія та липка оболонка взаємопов'язані.

## Вміст

- **Навчання (кімната 0):** один стілець, одна прірва, короткий маршрут, необмежені спроби. Герой відновлюється на старті, предмет повертається після падіння, біомаса повертається автоматично.
- **Кімната 1:** меблі та платформні головоломки. Створюйте проміжні опори за допомогою фіксації.
- **Кімната 2:** важкі предмети, залежність підіймання від біомаси, живі нитки й опори.

## Нове у v0.6

1. **Заряд кидка:** тримай E, побачиш силу 0–100% і зелений пунктир траєкторії; відпусти, щоб кинути. W/S під час заряджання змінюють кут.
2. **Climbable cytoplasm:** зафіксований предмет вкритий округлою живою оболонкою. До боків та нижнього слизового відростка можна прилипнути і повзти W/S та A/D; Space відштовхує від оболонки. Навіть предмет високо в повітрі має звисаючий відросток.
3. **Біомаса — фізика героя:** витрачання зменшує реальні фізичні габарити героя, його вантажопідйомність та потужність кидка. Звільнення повертає матеріал.
4. **Автоматичний refund:** якщо предмет падає в прірву, гра повертає закріплену біомасу та витрати на нитки, відновлює предмет біля початку рівня.
5. **No-loss:** у тренуванні падіння не знищує прогрес і не карає ресурси. N дозволяє почати спочатку в будь-якій кімнаті.

## Файли

- `index.html` — незалежний браузерний Canvas2D прототип (без зовнішніх ресурсів).
- `docs/index.html` — точна копія для GitHub Pages, опція branch main /docs.
- `Cytoplasm_GDevelop_v060.json` — GDevelop 5, подія з тим самим JS-ядром.
- `GameCore_v060.js` — ігрове ядро для розвитку та тестування.
- `GameScene_v060.js` — код GDevelop-події, зі спільним ядром.
- `tests/test_core_v060.cjs` — тести механік.

GDevelop JSON перевірений структурно. Окремо потрібно вручну запустити Preview у редакторі й перевірити фізику повного проходження на реальному PC.
