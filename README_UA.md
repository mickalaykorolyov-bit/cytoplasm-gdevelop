# CYTOPLASM — CLICK • BOUNCE • BLAST v0.7.1

**Іграбельний PC прототип · 16:9 · 1280×720**

## Що виправлено за відгуком

1. **Лівий клік миші = миттєво створити желе саме там, де клікнув.** Більше немає невидимих пострілів і затримки польоту. Якщо натиснув на предмет, желе обволікає й прив'язується до самого предмета, тому його центр повторює центр меблів. Є невелика пауза між кліками 0,105 с для захисту від випадкових повторів.
2. **Стілець у желе не просто декорація.** Захоплена річ зупиняється в повітрі, желе стає **супербатутом** (помітно вищий відскок), а після `R` предмет вилітає вперед, як снаряд. У третій кімнаті ним можна **розбити червону перешкоду перед виходом**. Особливий батут відзначений жовтим ободом та ↑↑.
3. **Безглузді ящики, що падали зверху, видалені.** Є один важкий ящик, що стоїть на платформі у другій кімнаті. Клік по ньому запускає накопичення тиску (жовтий індикатор), а за приблизно секунду — вибух із фізичним поштовхом.

## Керування

| Дія | Як робити |
|---|---|
| Створити желе | **Лівий клік** у потрібній точці |
| Підірвати останнє желе | **R** |
| Рухатися | **A/D**, стрілки |
| Стрибати | **Space** |
| Лазити по желе | **W/S** біля оболонки |
| Перезапустити кімнату | **N** |
| Альтернативне створення желе з клавіатури | E (в точці курсора) |

## Кімнати

1. **BOUNCE PLAYGROUND** — миттєво розміщуй желе, стрибай і вибухай без програшу.
2. **BLAST RUN** — стрибки через прірви і стоячий важкий ящик для Pressure.
3. **FURNITURE ROCKET** — желе на стільці дає сильний відскок, а вибух запускає його в крихку перешкоду.

Желе не зникає мовчки: вибух, старіння, заміна, падіння в прірву повертають біомасу та показують реакцію. Геймплей максимально аркадний; без ниток.
