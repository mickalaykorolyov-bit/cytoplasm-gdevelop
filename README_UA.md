# CYTOPLASM — Living Reactions v0.8.0

**Playable experimental physics laboratory · PC 16:9 · HTML + GDevelop JSON**

## Теза
**Одна цитоплазма + об'єкт = непередбачуваний, але логічний фізичний результат.** Більше немає чотирьох видів пострілів: просте желе — лише маленький батут. Усі інші реакції визначає світ.

## Керування
- **A / D** — пересування, **W** — стрибок (українська клавіатура теж працює через KeyW).
- **Лівий клік у точці** — герой стріляє згустком цитоплазми в точку кліку; видно політ і розгортання желе.
- **Другий клік по вже створеному желе** — вибух із фізичними уламками, які збивають ворогів і ламають перегородки.
- **R** — необов'язково підірвати найближче до курсора желе; **E** вимкнено.
- **S** — причепитися до желе, **W** — відштовхнутися.
- **1–6** — миттєво перейти в одну з шести експериментальних кімнат. **N** — перезапустити кімнату.

## Кімнати
1. **Основа + меблі**: мала пружна бульбашка, рухомий стілець, фіксація у повітрі, повторний постріл/уламки.
2. **Жива цитоплазма**: равлик на стелі, павук, їхня пружна оболонка, ріст, вибух і поштовх.
3. **Вогонь + гармата**: свічка запалює желе, полум’я поширюється, палаюча труба стріляє зарядом.
4. **Електрика**: батарея створює блискавку; метал проводить заряд; перемикачі відкривають бар'єр, вороги оглушаються.
5. **Сила + шип + шестерня**: важкий сейф стискає желе та вилітає; голка дає спрямований вибух, шестерня запускає уламки.
6. **Магнітна катапульта**: желе на магніті притягує метал, вибух розкидає снаряди, равлик на стелі працює як живий батут.

## Модель системи
- `createGel(x,y)` визначає контекст за фактичним попаданням у предмет або сутність.
- `updateInteractive(dt)` керує ростом живого желе, вогнем, електричними дугами, магнітом, тиском, шестернею, шипом і фізичними снарядами.
- `explode(pad)` застосовує спільну ударну хвилю та контекстний ефект. Уламки мають траєкторії та взаємодіють з ворогами й стінами.
- Кожна реакція має потенціал для **руху героя** (відскок, реактивний поштовх, гарматний постріл, рухома опора) і **впливу на світ** (снаряди, руйнування, підпал, перемикачі, оглушення).
- Невдалий стрибок не призводить до програшу: відновлення на платформі. Біомаса повертається ефектом частинок при руйнуванні желе.

Це прототип для тестування системної взаємодії, не фінальна гра. Для експериментів з механіками достатньо шести камер; баланс, графіка, звук і повні рівні будуть окремими ітераціями. Проєкт GDevelop використовує вбудований JavaScript-івент, як і попередні прототипи.
