# CYTOPLASM v1.1b ART PROTOTYPE — LUMEN GARDEN

**Один повністю оформлений стартовий екран** на основі v1.1a. Це реальна іграбельна збірка, а не статична ілюстрація.

## Художні зміни
- Темний біолюмінесцентний світ, акценти на герої, желе і безпечних мембранах.
- Великі розфарбовані клітини, органели, судини, капіляри, пульсуючі тканини.
- Чотири незалежні плани: far 0.12×, mid 0.35×, near 0.63×, foreground 1.13×.
- Напівпрозорі розмиті структури по краях кадру; вони не закривають персонажа.
- Перші дві опорні платформи і перший верхній місток отримали органічну форму.
- Небезпечні прірви оформлено як ферментні басейни.
- Безокі бактерії й віруси як частина нового мікросвіту.
- Дещо пружніші візуальні деформації героя й желе.

## Що не змінено
Повна фізика стрибків, реальні колізії, кількість ресурсів, бойова логіка, вся структура рівня, біокапсули, електрика, Bio Surge. Усі дальні секції після стартового екрану використовують попередні фони v1.1a для безпечної перевірки.

## Керування
A/D рух; W стрибок; лівий клік цитоплазма; R вибух; N перезапуск.

## Тест
Відкрий index.html локально або окреме браузерне прев'ю. Перевір першу прірву: створити желе, застрибнути та перейти на інший берег. Помічай рух шарів під час переміщення камери.
